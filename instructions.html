Simple Compile

← Back to Simple Compile

Open a Simple Minutes or Minutes file, pick the kind of output you need, and copy or share the result. There's no editing here on purpose — this page covers everything the app actually does, plus a few options worth knowing about.

Quick Start

  1. Open index.html and drop in a CSV — a Simple Minutes export, or a Master CSV from Minutes.
  2. Pick the type of output: Minutes Maker, SHMHA Minutes Book Submission, or Simple List.
  3. Adjust whichever options matter for that output.
  4. Copy to clipboard, or tap Share to hand the text to Mail, Messages, Notes, or whatever the device offers.

1. Open a File

  • Click to choose a file, or drop a CSV onto the page — either a file exported from Simple Minutes, or a Master CSV from the full Minutes app.
  • Opening a second file replaces the first outright — with a confirmation if the first one had real content already showing. Refreshing the page starts completely clean; nothing carries over between visits.
  • A file with no leader names at all (Simple Minutes' everyday output) is detected automatically, and "This singing's minutes don't name individual leaders" is checked for you. If a file has names on some songs but you still want them all left out, tick this by hand.
Checking "no names" also simplifies the options below it: the SHMHA Minutes Book Submission button and the Wording & Presentation section both disappear, since neither applies to a leaderless log. If SHMHA was already selected when you check it, the output switches back to Minutes Maker automatically.

2. Choose the Output

  • Minutes Maker — a real narrative write-up, patterned on how published Sacred Harp minutes actually read, not one flattened formula.
  • SHMHA Minutes Book Submission — matches the Sacred Harp Musical Heritage Association's printed submission format exactly. Always follows its own fixed rules regardless of any Minutes Maker option below it.
  • Simple List — a terse, events-only scan list: page number always shown, everything else optional.

Minutes Maker options

  • On every song call-out: song number, song title, the song's source (even when it's the day's default book), and ALL CAPS titles are each independent checkboxes.
  • Summary line at the end — number of singers present, number of leaders, number of songs. Left off entirely if nothing here is checked.
  • Per-song book identifier style — SingLoud work code, SHMHA code, or the book's Title Proper. This same choice also controls the wording of the opening "name every book" sentence (Title Proper switches its verb from "are marked" to "come from," since there's no code left to mark anything with).
  • Include a song index at the end — every page number used, grouped by tunebook (or titles, for anything logged as "Other").
  • Name the default tunebook edition near the opening — e.g. "Song selections were from The Sacred Harp: 1991 Edition."
  • Show edition for The Sacred Harp — spells out "The Sacred Harp: 2025 Edition" rather than the shorter "The Sacred Harp" alone, since both the 1991 and 2025 editions are still in common use. Every other book is unaffected. The same option exists in the full Minutes app; Simple Minutes doesn't carry it, by design.

Simple List options

Song Title, ALL CAPS, and the summary line reuse the same checkboxes as Minutes Maker above — configure them once. Page number itself is always shown; everything else is optional, so a single-book singing can be reduced to a plain column of page numbers:

  • Book Title Proper, SingLoud book code, and SHMHA book code — independent checkboxes, not one style choice; show as many identifiers side by side as are actually useful. A missing SHMHA code shows an em dash rather than a blank or a guessed code.
  • List every tunebook used — a header line beneath the location, first-appearance order.
  • Show the officer block — Chair, Secretary, and the rest, whichever positions have a name on file.

Wording & presentation (optional)

Applies to the narrative regardless of output type: a recurring-date pattern for an annual singing, one of five opening-paragraph styles, the presiding officer's title, and separate phrasing choices for the opening and closing prayer credits. Hidden entirely for the Simple List, and for any file marked "no names."

3. Copy or Share

  • The preview above these buttons always reflects the current output type and options — change anything and it updates immediately.
  • Copy to clipboard always works. Share hands the same text straight to Mail, Messages, Notes, or whatever the device offers, and is hidden automatically on a browser that doesn't support sharing.
  • Optional: tick add a line crediting SingLoud.org at the bottom if you'd like the output to say where it came from.
Every other app in this suite writes files. Simple Compile deliberately doesn't — the point was always "copy, paste, email," not producing another file to manage, so there's no download grid of formats here. If a finished CSV needs to be kept as a record, keep the original file you opened; Simple Compile is a one-way read of it, not a place to store it.

If Something Needs Fixing

Simple Compile has no editing surface at all — no Song List to correct, no book-source management, no saved project. If a file genuinely needs a name fixed, a page corrected, or a book source assigned, open it in the full Minutes app instead. The file you opened here is never changed by anything on this page, so it's still exactly as it was if you need to take it there.

Nothing Is Saved, Nothing Is Uploaded

Simple Compile keeps no project between visits and writes nothing to browser storage in either direction. No file, and no part of the minutes it generates, is ever sent anywhere — everything happens in the browser; Copy and Share hand text to the operating system, not to a server.

Where the Songbook Data Comes From

tunebook-library.js ships bundled right beside index.html, exactly like every other app in this suite — read strictly as data, never executed as code.

Troubleshooting

A file won't import, or imports with almost nothing recognized

Simple Compile shares the full Minutes app's own import logic, which is tolerant: it matches columns by name and recognizes several older or alternate column names. If a file truly imports with nothing usable, check that it has at least a Leader/Caller, Page, or Notes column under some name it recognizes.

SHMHA Minutes Book Submission isn't showing as an option

Check whether "no names" is ticked — that output type is hidden for leaderless files, since SHMHA's own format assumes named leaders. Uncheck it if this file should genuinely show names.

The preview doesn't match what I expected

Check which output type is selected — Minutes Maker, SHMHA, and Simple List apply different rules entirely. Also double-check the per-song book identifier style and the summary-line checkboxes, which change the wording without changing the type.

A book's code shows as an em dash

That's deliberate — it means this book genuinely has no SHMHA code on file, not that something went wrong. It's the same placeholder the Simple List's own SHMHA column uses for the same case.

I need to correct something in the file

Open it in the full Minutes app instead — Simple Compile has no editing surface by design.
